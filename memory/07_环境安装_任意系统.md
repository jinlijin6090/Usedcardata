# 本地环境安装（给负责安装的 agent）

## 推荐：conda / mamba（Windows、macOS、Linux 通用）

```bash
conda env create -f environment.yml        # 或 mamba / micromamba
conda activate co2ec
python -c "import rdkit, numpy, scipy, matplotlib, duckdb; print(rdkit.__version__)"   # 应为 2026.09.1
```

不用 conda 时：`python -m pip install -r requirements-research.txt`（Python 3.10–3.13）。

## 验证

```bash
python ec_space/run.py --selftest                   # 约 1 分钟，应输出：通过 [2, 5, 17, 77, 379, 2270]
cd co2_hydrogenation_network/scripts && python route_figure.py   # 应生成 figures/route_shared_network.png
```

## 各部分对系统的要求

| 部分 | Windows 原生 | macOS | Linux |
|---|---|---|---|
| `ec_space`（`run.py`） | 可以（自动用 spawn） | 可以 | 可以；也可以用 `run.sh` 和自带的 conda-pack 环境 |
| `network_gen.py`、`lod_build.py`、`isomer_scale.py`（依赖 fork） | 不行，请用 WSL2 | 可以 | 可以 |
| 网页（`web/*.html`、`ec_space` 输出的 viewer） | 双击离线版即可 | 同左 | 同左 |
| PPT 生成 | 需要 Node.js 18+；在 `deck/` 下 `npm install` | 同左 | 同左 |
| `tandem_kinetics` | 可以 | 可以 | 可以 |

## 其他

- **字体**：`co2_hydrogenation_network/assets/fonts/` 已包含，作图脚本会自动加载，不需要系统安装。
- **Linux 一键环境**：仓库 `downloads/EC化学空间枚举程序/ecenv.tar.gz.part-00…03`（RDKit 2026.09.1、numpy、DuckDB）。放到 `ec_space/env/` 后运行 `bash ec_space/run.sh --selftest`。
- **可选**：用 `pip install playwright && playwright install chromium` 做网页截图检查（会话里就是这样测试网页的）。
- **ni_cu_ce_al2o3 子项目**：另建环境 `environment-nicu.yml`（ase、torch、mace-torch），与主线无关。
