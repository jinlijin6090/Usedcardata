### 1. 中间体与反应怎么枚举的
- **分子**：自己写了生成器，每次加一个碳或氧原子，把所有价键合理的结构都列出来。C+O ≤ 9 个重原子（共 78.9 万个分子）全部精确枚举，烃类数到 C10。和已知的异构体数核对，完全一致（如 C₆H₁₂ = 25、C₈H₁₈ = 18、C₄H₁₀O = 7）。
- **自由基**：每个分子在每个不等价的带 H 位置去掉一个 H，就是一个单自由基。
- **反应**：共 14 类基元反应，包括自由基复合/断键、H 加成和自由基加成到双键（如 H + CO₂ → HOCO/HCOO）、成环/开环、CO 插入、H 迁移、H 抽提、歧化、自由基取代、脱水等四中心消除、脱羰（如 HCOOH → CO + H₂O）、酮–烯醇互变、Diels–Alder。反应物与反应物、反应物与产物、产物与产物之间都可以反应。
- **可直接查看的完整网络**：C≤1 有 19 个物种、141 个反应；C≤2 有 96 个物种、4649 个反应，每条反应都列在文件里。

### 2. 规模量级
| 碳数上限 | 分子 | 自由基 | 反应 |
|---|---|---|---|
| C≤2 | 38 | 58 | 4.7×10³ |
| C≤6 | 4.8×10⁴ | 1.9×10⁵ | 4.4×10¹⁰ |
| C≤12 | ~4×10¹⁰ | ~3×10¹¹ | ~10²³（1.5×10²²–2×10²³） |

- 每多一个碳，物种数增加约 7–9 倍。
- 去掉高张力结构（双环丁烷、桥环等）后，C12 仍有约 3×10⁹ 个分子、10²¹ 个反应。
- **反应数主要来自任意两个自由基之间的 H 抽提和歧化**，这部分随自由基数的平方增长。其他所有反应类型加起来只有约 2×10¹²。
- 外推检验：用较小体系外推出的 C10 烃数是 1.31×10⁶，之后精确数出 1,333,965，误差 1.6%。

### 3. 已知产物后能缩小多少
做法有两步：
1. 物种只保留产物碳骨架的子结构，加氢程度从全饱和到产物本身都保留，再加上全部 C1 中间体。
2. H 转移类反应的伙伴只保留 H、OH、CH₃、HCO、CH₃O、HOCO 这类小自由基。

第二步把随自由基数平方增长的部分变成线性增长。

| 场景 | 物种 | 反应 | 缩小倍数 |
|---|---|---|---|
| 甲烷化（Ni / NiCu） | 21 | 155 | ~10²¹ |
| 甲醇（Cu/ZnO） | 28 | 279 | ~10²⁰ |
| CO₂ 费托合成（Fe–K），C1–C12 | 338（加含氧中间体：5×10³） | 6.3×10³（1.2×10⁵） | 10¹⁸–10¹⁹ |
| CO₂ 制芳烃（氧化物/分子筛），BTX 到二甲基萘 | 9×10⁴（加含氧中间体：1.5×10⁶） | 2.1×10⁶（3.9×10⁷） | 10¹⁵–10¹⁷ |

还可以用速率剪枝或集总（如 ASF 链增长参数）再缩小 1–2 个数量级，这一步我没有做。

### 局限
- 这是气相自由基的写法。对应到催化表面，R• 相当于 R*，H 转移的伙伴相当于 H*/OH*，本身就符合"小自由基池"这个近似。
- 表面多齿中间体（C*、CH* 等）对应双自由基，C12 时约 8×10¹¹ 个，只计了数，没有放进反应网络。

### 二、反应网络和动力学模型
甲醇是氧化物和分子筛之间的中间体，分子筛上的链增长走碳正离子化学，不是之前那套自由基网络。所以我按"类别 × 碳数"搭了一个集总网络：72 个物种、296 个反应，覆盖甲基化、齐聚、裂解、氢转移、芳构化等步骤。网络耦合了氧化物上的甲醇和逆水煤气变换（RWGS）动力学，以及平推流反应器（PFR）。

用郭组两篇（GaZrOx、ZnZrO）和 Gao 2017 In₂O₃/HZSM-5 对照，共三组数据校准，所有拟合目标都能复现。下面的结论只靠动力学得出：

1. **转化率由氧化物上的甲醇生成控制。** 转化率对甲醇生成速率常数的敏感度是 0.66，对分子筛各步都低于 0.05。分子筛的作用是把甲醇抽走：同样的氧化物量，单独用氧化物时 CO 选择性 68–94%，和分子筛组合后降到 12–45%。
2. **芳烃有约 50% 的氢平衡上限。** 每生成一个芳环要放出 6 个氢；只靠氢转移，就得同时生成 3 个烷烃。ZnO/ZrO₂–ZSM-5 的 70% 芳烃，只有加上"脱氢放出 H₂"这条通道才拟合得出来。热力学上，这一步从环烯类中间体出发可行，从饱和环烷出发不可行。由此推断 Ga/Zn 一类位点的脱氢功能是高芳烃的关键，这和郭组做 Ga 体系的方向一致。
3. **摘要数据无法确定航煤潜力。** 我做了 32 组拟合，每组都同样准确地复现 GaZrOx 的四个数，但它们对没测量的量给出的预测差别很大：
   - 芳烃：7–78%
   - C8–C16：36–65%
   - 实际能做航煤的部分：0–41%
4. **ZSM-5 体系的"航煤馏分"主要是芳烃。** C8–C16 本身有 46–60%，但约 88% 是 C8–C10 芳烃。按芳烃不超过 25% 的调和上限，真正能用作航煤的只有 2–8%。只换大孔分子筛基本没用，因为重链在长到孔径上限之前就被裂解掉了。
5. **调节方向。** 下面的趋势在 12 组参数中方向一致：
   - 降低温度，能做航煤的部分从约 2% 升到约 42%，但转化率随之下降；
   - 提高氧化物比例，从约 6% 升到约 29%；
   - 提高空速和压力也有帮助。

   对能做航煤的部分最敏感的因素是裂解（敏感度 −0.92）和烯烃加氢（+0.39）。所以，要做烷烃型航煤，方向是加氢强、裂解弱、少脱氢，正好和高芳烃催化剂相反；代价是转化率降低。

### 用户（2026-11-03 13:31 UTC）

metal site指的是什么

**助手（2026-11-03 13:31 UTC）**

这里有两层意思：

**1. 化学上的"金属位"**

指金属或金属碳化物催化剂表面的活性中心，比如 Fe 基 CO₂-FTS 催化剂里的 χ-Fe₅C₂、θ-Fe₃C，以及 Co、Ru，也包括 Cu、Ni 这类加氢金属。它们的作用是解离 H₂ 得到 H*，解离或活化 CO 得到 CH₂* 这类 CHₓ* 单体，再让碳链在表面一节一节长大，属于费托（FT）路线。

在网络里，这类反应都归到"金属/碳化物"那一组（图上的红色背景区），包括：

| 反应 | 含义 |
|---|---|
| R* + CH₂* → RCH₂*（CH₂* 插入） | 碳链增长，每次加一个碳；支链也能长出来 |
| R* ⇌ 烯烃 + H*（β-H 消除） | 表面烷基脱下来，变成 α-烯烃或内烯烃 |
| R* + H* → 烷烃（加氢终止） | 生成直链或支链烷烃 |
| R* + CO* → RCO*（CO 插入） | 生成酰基，接着加氢得到醛和醇；高级醇就是这条路线来的 |
| R* + OH* → ROH | 另一条生成醇的终止方式 |

和它相对的是郭新闻组用的 OX-ZEO 路线：ZnZrOₓ、In₂O₃ 这类氧化物先把 CO₂ 加氢成甲醇或甲酸盐中间体，再到分子筛（HZSM-5 等）的 Brønsted 酸位上走碳正离子化学，也就是蓝色区域的那些反应。

一个真实催化剂会以哪条路线为主，取决于它的组成。网络里两条路线都枚举出来了，图上用不同底色区分，所以可以对照文献的产物分布，判断哪部分在起作用。

**2. 程序日志里的"site"**

日志里写的 "site species" 不是"金属位"，而是 **C–H 位点**的意思。这一步遍历每个烷烃里每个化学上不等价的 C–H 位置，在这个位置上生成：

- **吸附烷基 R\***：该位置的碳连到催化剂表面；
- **气相自由基 R•**：该位置的碳失去一个 H；
- **对应的含氧化合物**：醇（及表面烷氧基）、醛（及酰基）、酮、羧酸。

然后再写出这些物种之间的反应，也就是上面那张表，加上醇脱水、羰基加氢、醛氧化成酸，以及自由基的 H 抽提和 β-断裂。

**助手（2026-11-04 00:49 UTC）**

"烯烃池"（olefin pool）是分子筛上甲醇转化成烃类（MTO/MTH）机理里的概念，在 CO₂ 一步加氢的分子筛那一段同样适用。

**1. 背景：双循环机理**

甲醇或二甲醚在分子筛（如 HZSM-5、SAPO-34）里转化成烃，现在公认的是"双循环"机理（Svelle、Olsbye、Bjørgen 等，2006 年前后提出）。分子筛孔道里滞留着一批起"催化中心"作用的烃类物种，统称"烃池"（hydrocarbon pool）。按它们的种类分成两个互相耦合的循环：

| | 烯烃循环（烯烃池） | 芳烃循环（芳烃池） |
|---|---|---|
| 池里的物种 | C₃–C₈ 左右的烯烃，以及它们质子化后的碳正离子 | 多甲基苯（二甲苯到六甲苯）及其正离子 |
| 怎么运转 | 甲醇以表面甲氧基（SMS）的形式给烯烃加甲基，碳链一个个变长（C₃→C₄→C₅…），长到一定程度发生 β-断裂，又碎成丙烯、丁烯等，碎片继续被甲基化，如此循环 | 甲醇给芳环加甲基，多甲基苯再通过侧链甲基化或"削皮"（paring）机理，把甲基以乙烯、丙烯的形式"吐"出来 |
| 主要产物 | 丙烯、C₄+ 烯烃，以及支链烷烃（汽油、航煤馏分） | 乙烯、芳烃 |
| 偏向哪种分子筛 | 十元环、孔道较开放的 ZSM-5 | 八元环笼的 SAPO-34，以及积累芳烃之后的情况 |

两个循环之间有交叉：烯烃池里的烯烃经过氢转移、成环、脱氢，会变成芳烃，从而补充芳烃池。这一步同时生成烷烃，所以产物里烷烃增多、芳烃增多。

**2. 为什么叫"池"**

这些烯烃和碳正离子不是一次性的中间体，而是在孔道里反复被甲基化、反复断裂，整体浓度维持在一个大致稳定的水平，像一个"库存"。真正进出这个库存的是：甲醇进去，轻烯烃和更大的烃出来。它们同时起着类似催化剂的作用（自催化），这也是 MTO 反应有"诱导期"的原因：要先积累起这个池子。

**3. 和航煤（SAF）的关系**

郭新闻组这类氧化物/ZSM-5 串联体系，想多出 C₈–C₁₆ 的航煤馏分，关键就在于让烯烃循环占优势：
- 烯烃反复甲基化、齐聚到 C₈–C₁₆，β-断裂又不要太强；
- 同时抑制芳烃循环和过度的氢转移。否则产物会偏向乙烯、芳烃和轻烷烃。

**4. 在我做的网络里它对应什么**

  - SMS 甲基化（Z:meth）
  - β-断裂/齐聚（Z:beta）

**助手（2026-11-04 05:49 UTC）**

碳正离子和自由基是同一个碳骨架被"活化"的两种方式。它们出现在不同的催化环境里，走的化学也不一样。网络里两种都放进来，是因为一开始的目标是"枚举所有可能的中间体，包括自由基"，把可能性都覆盖到。实际谁占主导，要由反应条件决定。

**1. 区别在于 C–H 键怎么断**

以丙烷为例，从同一个分子上拿掉一个氢，有三种拿法：

| | 碳正离子 R⁺ | 自由基 R• | 吸附烷基 R* |
|---|---|---|---|
| 怎么形成 | 异裂：氢带着一对电子离开（负氢转移），或者烯烃接受一个质子 H⁺ | 均裂：氢只带一个电子离开（H 原子被抽走），或者 C–C 键受热断开 | 碳原子直接和金属表面成键（M–C） |

**助手（2026-11-04 09:15 UTC）**

生成分三层：先硬枚举所有闭壳层分子，再从每个分子派生出它的自由基、离子和 Li⁺ 配位物，最后从每个物种生成它参与的基元反应。下面按这个顺序讲，每一步说明为什么既不会漏、也不会重复。

## 1. 闭壳层分子：逐个加重原子，一层一层长

**起点**：第 1 层只有 CH₄ 和 H₂O，也就是只有一个重原子的分子。H 不单独枚举，每个原子缺多少价就补多少个 H。

**从第 n 层到第 n+1 层**：对第 n 层的每个分子：
1. 新加一个 C 或 O 原子；
2. 把它连到原分子里任意一组还有空余价的原子上，键级可以是单键、双键或三键；
3. 新原子的价必须不超（C ≤ 4，O ≤ 2），被连的原子要有空位（去掉相应的 H）。

新原子只连一个旧原子，就是长链或长支链；同时连两个或更多旧原子，就是成环。例如：

| 父分子（第 5 层） | 加一个 O，同时单键连到甲酰基 C 和末端 CH₃ | 结果（第 6 层） |
|---|---|---|
| 甲酸乙酯 O=COCC | 成环 | EC（O=C1OCCO1） |

**为什么不会漏**：任何一个有 n+1 个重原子的连通分子，总能找到一个删掉后分子不会断开的原子（图论里的"非割点"；比如链端原子，或者环上的原子）。删掉这个原子，剩下的就是一个合法的 n 原子分子，这个分子一定在第 n 层里。反过来，第 n 层的这个分子"加回那个原子、连回原来那些键"，就重新生成了这个 n+1 原子分子。所以逐层加原子能走遍所有分子。

**几个细节**：
- **芳香分子**：把它的所有凯库勒式（单双键交替的写法）都展开一遍再加原子，否则会漏掉"只在某种单双键写法下才能接上去"的结构。
- **对称性剪枝**：如果新原子只连一个旧原子，对称等价的旧原子只连一次。比如乙烷的两个 C 等价，只连其中一个。这只是省时间，不影响结果。
- **剪掉不可能的结构**：每生成一个分子就检查一次，不合格就直接丢掉，后代也不会再生成：
  - 8 元以下的环里有三键或累积双键（如 =C=），几何上无法成环；
  - O–O–O 链；关掉过氧键选项时，任何 O–O 都去掉。

  这些规则有一个性质：一个分子不合格，它加了更多原子的后代也一定不合格（不合格的片段还在）。所以边生成边剪枝不会误伤。

**去重**：同一个分子会从很多条路径被生成出来，比如从不同的父分子、或连到不同位置。每个分子都转换成 RDKit 规范 SMILES，再"读回—写出"往返校验，直到字符串不再变化（防止同一分子出现芳香式和凯库勒式两种写法）。规范 SMILES 相同就算同一个分子。

**并行和大规模**：第 12 层大约有 10⁹ 个分子，内存放不下，所以去重放在磁盘上做：
1. 多个进程分头处理父分子；
2. 子分子按 SMILES 的哈希值分到几百到几千个分片文件里；
3. 每个分片单独读进内存去重、排序，再写出；
4. 每层完成后写一个 `DONE.json`，作业中断后从这里继续。

**核对**：关掉过氧键时，1–9 层的分子数和之前另一套独立实现的枚举逐层对得上（2、5、17、77、379、2,270、15,196、…、964,497）。另外，丁烷 2 种、戊烷 3 种这类已知的同分异构体数，之前也核对过。

**注意**：这里只枚举构造异构（原子怎么连），不区分立体异构（顺反、手性）。

## 2. 派生物种：在每个分子的"位点"上做一次或两次修饰

对每个闭壳层分子，先找出它的对称不等价原子，然后做下面这些操作：

| 操作 | 结果 | EC 的例子 |
|---|---|---|
| 去掉一个 H•（C 或 O 上） | 自由基 R• | `O=C1O[CH]CO1` |
| 去掉一个 H⁺ | 负离子 R⁻ | `O=C1O[CH-]CO1` |
| 去掉一个 H⁻（默认只在 C 上） | 碳正离子 R⁺ | `O=C1O[CH+]CO1` |
| O 上加一个 H⁺ | 质子化 MH⁺ | `[OH+]=C1OCCO1` |
| 整体加一个或减一个电子 | 自由基阴离子 / 阳离子（电子不定在某个原子上） | `O=C1OCCO1\|-1` |
| 两个位点各做一次：一个自由基 + 一个负离子 | 远端自由基阴离子 | `[CH2]COC(=O)[O-]`（EC 开环后的产物，它的母体是碳酸单乙酯 CCOC(=O)O） |
| 两个 O 上各去一个 H⁺ | O 中心二价阴离子（LEDC 就是这种二价阴离子配 2 个 Li⁺） | |
| 以上任何物种的 O 上配位 1–2 个 Li⁺ | Li⁺ 配位物 | `[Li+]<-[O]=C1OCCO1` |

最后只保留总电荷在设定范围内的物种（默认 −2 到 +1）。

**为什么不需要全局去重**：每个派生物种都能"把去掉的 H 加回到带自由基或电荷的那个原子上"，唯一地还原出它的母体分子。比如 `[CH2]COC(=O)[O-]` 在 CH₂ 上加回 H、在 O⁻ 上加回 H，只能还原成碳酸单乙酯。所以不同母体派生出的物种一定不同，只需要在同一个母体内部去重。这一步因此可以按母体分配给不同进程，边算边写，不用把十亿级的数据放进内存。

## 3. 基元反应：每条反应只由一方负责生成

一条可逆反应有两边，如果两边都去生成，就会重复。所以规定每条反应只由某一个物种负责写出：

| 由谁负责 | 反应族 | 例子 |
|---|---|---|
| 派生物种 | 它和母体之间的那一步（加减 H•、H⁺、H⁻、e⁻、Li⁺） | `EC ⇌ O=C1O[CH]CO1 + H•`；`EC + Li⁺ ⇌ [Li+]<-[O]=C1OCCO1` |
| 母体分子 | 每根单键的均裂和异裂（逆反应就是自由基复合、离子复合） | `A–B ⇌ A• + B•`、`A–B ⇌ A⁺ + B⁻` |
| 母体的自由基阴 / 阳离子 | 断一根键，带走自由基和电荷；环上的键断开就是开环 | `EC•⁻ → [CH2]COC(=O)[O-]`（SEI 形成的第一步） |
| 每个只有一个自由基中心的物种 | β-断裂（逆反应是自由基加成）；断的是环上的键就是开环 | `O=C1O[CH]CO1 → C=COC([O])=O` |
| 双位点物种 | 由两个单位点物种各走一步形成 | |

**产物检查**：每条反应的产物都要检查：产物属于不在设定范围内的物种类别时（比如没打开双自由基选项，却断出了双自由基），这条反应就不写。这样保证反应表里提到的每个物种都在物种表里。

**不枚举的反应**：任意两个大物种之间的双分子反应，比如 R• + R′H 的 H 抽提。它的数量是物种数的平方，约 10²⁰ 条。自由基复合、离子复合、自由基加成已经作为断键和 β-断裂的逆反应包含在内。

## 4. 规模控制

- **写出范围**：`derive_max_heavy` 以内的层，派生物种和反应逐条写出。更大的层只按固定比例抽样派生，用来估算总数（抽哪些由 SMILES 的哈希值决定，结果可以重现）。闭壳层分子始终全部写出。
- **规模估算**：`estimate` 阶段先在本机把前 7 层精确算一遍，然后：
  1. 用实测的层间增长倍数，外推后面各层的分子数；
  2. 用实测的每个分子派生多少物种、多少反应、花多少 CPU、占多少磁盘，算出资源表。

## 5. 网页里的路径怎么算

- **最少步数**：把每条反应拆成正、逆两个方向。从 EC 出发（e⁻、Li⁺、H•、H⁺、H⁻ 始终可用），一层一层往外推：一条反应的全部反应物都已经能到达时，它的产物就是"再多一步"能到达的。每个物种第一次被到达时的层数，就是它的最少步数。
- **最短路径**：每一步只回溯步数恰好少 1 的那个主反应物，并预先算好每个物种有多少条这样的最短路径。

**两个约定**：
- 共振结构按定域写法分别计数，比如五二烯基自由基的不同写法算不同的条目。这和之前 CO₂ 网络的处理一样。
- 自由基阴 / 阳离子不定域，用"母体 SMILES|±1"表示。

以后如果需要按共振结构合并，可以在数据库里按骨架连接方式和 H 数做分组合并，程序本身不用改。
