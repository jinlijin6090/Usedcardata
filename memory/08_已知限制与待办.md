# 已知限制与待办

## 方法限制（回答用户时要说清楚）

- **只区分构造异构**：没有立体异构（顺反、手性）。CO₂ 的 isomer_scale 有单独的 E/Z 计数。
- **共振结构按定域写法分别计数**：自由基阴 / 阳离子不定域，用 `母体|±1` 表示。如果要按共振合并，可以按"骨架连接 + H 数 + 电荷 + 多重度"分组。
- **双分子反应**：
  - CO₂ 网络：负氢转移和芳烃间烷基转移只计数；
  - EC 网络：任意两个大物种之间的反应不枚举，复合、加成作为断键反应的逆反应包含在内。
- **伯碳正离子不计**（CO₂ 网络）。EC 网络默认只要碳正离子，不要 oxenium。
- **择形规则（C13–C16）是近似**：会让 158 个取代茚满 / 四氢萘不可达。
- **路线对比只看连通性**："可达"只说明拓扑上能到，不代表实际选择性。没有用热力学或动力学过滤。
- **动力学模型**：只用摘要级数据校准，参数不可辨识（见 tandem_kinetics README 3.3）。真正需要的是 PIONA / GC×GC 产物数据。
