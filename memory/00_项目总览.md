# 项目总览

## 背景

用户研究 CO₂ 一步热催化加氢制航煤（可持续航空燃料 SAF）。关心的是：
- 有哪些中间体（含自由基、碳正离子）；
- 反应网络有多大；
- 已知产物分布后网络能缩小多少；
- 大连理工郭新闻课题组的工作；
- 只用动力学模型能得到什么机理信息；
- 甲烷干重整 → 费托 → 提质，与 CO₂ 直接加氢这两条航煤路线的关系。

后来又扩展到锂电电解液：EC（碳酸乙烯酯）分解与自反应的化学空间要硬枚举，用户在自己的服务器上跑。

## 主线一：CO₂ 加氢网络（`co2_hydrogenation_network/`）

| 成果 | 关键结论 / 数字 |
|---|---|
| 全化学空间估计（C ≤ 12，O ≤ 2） | 闭壳层分子约 4×10¹⁰，自由基约 3×10¹¹，基元反应约 10²³（主要来自任意两个自由基之间的 H 转移，∝ N²）。知道产物后可缩小 15–20 个数量级 |
| 郭新闻组文献调研（`reports/`、`research_notes/`） | 摘要级证据。Fe 基 CO₂-FTS：约 40% 转化率下 C₂–C₄ 烯烃 36–37%。GaZrOx/Ga-ZSM-5（OX-ZEO）：17.2% 转化率下 C5+ 83.2%。没有公开的航煤数据 |
| 串联动力学模型（`tandem_kinetics/`） | 72 个物种、296 个集总反应，只用文献校准（G1、G2、B1 三个体系）。结论见下 |
| 同分异构体网络规模（`scripts/isomer_scale.py`） | C10 约 1.2 万个物种、4.3 万条反应；C12 约 9 万个物种、39 万条反应；每多一个碳 ×2.7 / ×2.9 |
| 显式逐条反应网络（`scripts/network_gen.py`） | 推荐版（C1–C12 全部异构体 + C13–C16 ZSM-5 择形）：128 390 个物种、367 369 条基元反应。全量 C16：4 776 003 个物种、15 500 138 条基元反应，只有 17 个物种从 CO₂ 不可达，最远 22 步 |
| 交互网页（`web/`） | 推荐版单页（WebGL）和全量分级加载页。都能列出物种的全部反应，并找出从 CO₂ + H₂ 出发的最短路径。另有离线单文件版 |
| PPT（`deck/`） | 6 套网络图：C1 详细网络、催化剂分类色块、同分异构体单页、C1–C10 全异构体单页等 |
| 两条航煤路线对比（`scripts/route_compare.py`、`figures/route_shared_network.*`） | 全量网络里 DRM→FT→提质 与 CO₂ 直接加氢共享 99.9998% 的物种（C2 以上 100%，B 独有的只有 9 个 C1 入口物种），共享 91.6% 的基元反应（B 多出的是 SMS 甲基化） |

动力学模型的主要结论：
- 转化率由氧化物上的甲醇生成控制，分子筛速率常数的敏感度 < 0.05；
- 只靠氢转移时，芳烃选择性有上限 S_A ≤ n_A /(n_A + 3 n̄_P)，约 48%；高芳烃体系需要 Ga/Zn 位的脱氢芳构化；
- 只有转化率、CO、C5+、CH₄ 这些数据不足以判断催化剂的航煤潜力（可辨识性分析）；
- MFI 分子筛里的"C8–C16"约 88% 是 C8–C10 芳烃；碳数上限由生长和裂解的竞争决定，而不是孔径。

## 主线二：EC 化学空间硬枚举（`ec_space/`）

- 程序可以在服务器上一键运行：多进程，磁盘分片去重，断点续跑，带完整 Python 环境（conda-pack，Linux x86-64），也可以按 `environment.yml` 在任意系统安装。
- 默认枚举 ≤ 12 个重原子（两个 EC 的重原子数）。内容：
  - 全部 C/H/O 闭壳层分子；
  - 自由基、正负离子、质子化物、自由基阴/阳离子；
  - 远端自由基阴离子、O 中心二价阴离子；
  - 1–2 个 Li⁺ 配位物；
  - 14 类基元反应。
- 默认规模估计：
  - 物种约 1.7×10¹¹、反应约 3.6×10¹¹；
  - CPU 约 1 400 核时；
  - 写出约 8 GB（9 个重原子以内逐条写出，更大的层抽样计数）。
- 正确性：关掉过氧键时，闭壳层分子数与独立实现逐层一致，到 9 个重原子是 964 497。
- 另一个精确结果：如果每个物种的原子只能来自两个 EC（C ≤ 6、O ≤ 6、H ≤ 8），则有 2 671 907 个闭壳层分子、11 279 481 个单自由基。
