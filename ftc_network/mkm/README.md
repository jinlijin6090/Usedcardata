# 随机参数微观动力学：哪一步控制 α（进行中）

目标：不做 DFT，先给表面费托网络的每个物种、每个反应分配"在合理范围内的随机能量"，

## 1. 网络（`surface_network.py`）

* 自由价 = 表面键数：CH3* (1)、CH2* (2)、CH* (3)、C* (4)、CO* 写成 `[C]=O` (2)、HCO* (1)。
* 每个吸附物种占 1 个位点（平均场、单一位点类型）。
* 自由价为 0 的含 C 物种（烷烃、1-烯烃、醛、醇）和 H2O 生成即离开表面，产物分压为 0
  （差分反应器；暂不含烯烃再吸附）。H2 只通过解离吸附进入。
* 物种空间：H*、O*、OH*；C1 全部（至多 1 个 O，自由价 ≤ 4）；C2–C_nmax 直链，
  只有一端（活化端）带剩余价，O 只能是连在活化端碳上的端基 O，至多 1 个 π 键，自由价 ≤ 3。
* 反应：b0f1/b1f0（A + B ⇌ C）、分子内 b1f1（H 迁移）；链物种只和 C1、H、O、OH 结合。
  另有 CO(g) + * ⇌ CO*、H2(g) + 2* ⇌ 2H*（待在 kinetics 中加入）。
* 规模：n_max = 10 时 162 个物种（112 个吸附物种、50 个气相产物）、546 个可逆反应，生成 0.4 s。
* 反应类别（决定能垒分布，也用于"类控制度"）：CO直接解离、H辅助C–O断裂(C1)、链上C–O断裂、
  C1加氢(C–H)、链端加氢/脱氢(C–H)、O加氢、C–O–H 加氢、水生成、C1–C1偶联、链增长
  （细分 +CH3/+CH2/+CH/+C/+HCO…）、CO插入、终止:加氢成烷烃、终止:β-H消除成烯烃、
  终止:偶联成产物、β-C断裂(链裂解)、含氧产物生成、H迁移。

## 2. 能量模型（`energetics.py`）

不能给每个反应独立随机反应能：网络里有环（例如 CO* 先断 C–O 再加 H，与先加 H 再断 C–O），
独立随机会破坏热力学一致性（相当于永动机）。因此随机的是**物种能量**，反应能由其相减得到。

* 物种能量 = −(键能加和 + 表面键结合能) + 吸附物种噪声 N(0, 0.1 eV)：
  键能 D_CH、D_CC、D_CCπ、D_CO、D_COπ、D_OH；表面键按标度关系 b_C = E_C/4、b_O = E_O/2。
  锚点：CO* = −(11.11 + E_ads,CO)、H* = −b_H、H2 = −4.52、H2O = −2 D_OH。
* 每个样本对这些参数在 `THERMO_RANGES` 范围内均匀抽样。
* 过渡态：E_TS = max(E_初态, E_终态) + E_int；E_int = 类均值 μ_c（每个样本 ~U(lo, hi)，
  见 `BARRIER_RANGES`）+ 每个反应 N(0, 0.1 eV)。同类反应因此相关（类似 BEP）。
* 冒烟测试（200 个样本）：

| 反应 | ΔE 范围（eV） |
|---|---|
| CO* → C* + O* | −1.06 ~ +0.98（偏宽，可收窄 b_C、b_O、E_ads,CO 的范围） |
| CO* + H* → HCO* | +0.34 ~ +1.66 |
| CH* + H* → CH2*、CH3* + H* → CH4 | −0.23 ~ +0.38 |
| CH2* + C2H5* → C3H7* | −0.59 ~ +0.25 |
| C3H7* → C3H6 + H* | +0.27 ~ +1.15 |
| C2H5* + CO* → C2H5CO* | +0.31 ~ +1.38 |
| H2 → 2H* | −0.87 ~ −0.38 |
| CO + 2H2 → –CH2– + H2O（气相） | −2.13 ~ −0.94 |

## 3. 待实现：动力学与分析（`kinetics.py`、`run_alpha_study.py`）

* 条件：500 K，P_CO = 6.67 bar，P_H2 = 13.33 bar。
* 速率常数：表面反应 k = (k_B T/h) exp(−ΔE‡/k_B T)，正逆反应共用一个 E_TS；
  吸附用 Hertz–Knudsen（位点面积约 6.5e-20 m²，粘附系数 1），脱附由平衡常数给出，
  吸附熵损失取气相标准熵（500 K：CO 约 212.8、H2 约 145.7 J/mol/K）。
* 稳态：dθ/dt = S·r(θ) = 0，θ* = 1 − Σθ。先 BDF 积分（解析雅可比），再在对数覆盖度上做牛顿迭代。
  链物种覆盖度按 α^n 递减，会跨很多个数量级，必须 float64。
* α：C3–C7 产物（烃 + 含氧物）生成速率的 ASF 拟合斜率（避开 n_max 附近的截断效应）。
* 选择性控制度：X_j = ∂ln α / ∂ln k_j（k_f、k_r 同乘，即只移动过渡态）。
  稳态隐式微分：dθ/dp = −J⁻¹ S diag(r)，一次线性求解得到所有反应。
  检验：Σ_j X_α,j = 0、对 CO 消耗速率 Σ_j X_TOF,j = 1，并用有限差分抽查。
* 类控制度：同类反应的 X 相加。
* 系综：100–1000 个样本；统计每个样本的主控反应与主控类别、类控制度的分布，
  以及 ln α 对各类能垒均值、热力学参数的全局敏感性（标准化回归 / Spearman）。
