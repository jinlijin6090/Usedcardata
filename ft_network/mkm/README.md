# 钴基费托集总微观动力学模型（MKM）

问题：用文献中钴表面的 DFT 能垒搭一个 MKM，能否拟合出实验的产物分布？

- 文献数据表：[LITERATURE.md](LITERATURE.md)（DFT 能垒、吸附能、实验活性/选择性/动力学、已发表的 MKM）
- 结果图：[../figures/co_mkm_fit.png](../figures/co_mkm_fit.png)

> 文献数值全部来自摘要和搜索摘要，未核对原文（本环境打不开出版社全文）。实验基准取 210 °C、20 bar、H2/CO = 2.1、低转化率、Co 颗粒 > 10 nm。

## 1. 从文献中拉出来的基元反应网络

文献中钴基 MKM 的网络可以归结为下面几组（括号内为文献能垒范围，eV）。本模型对每一组保留一条代表步骤：

| 组 | 文献中的步骤 | 本模型的代表步骤 | DFT 先验 Ea |
|---|---|---|---|
| 吸附 | CO、H2 吸附 | CO(g)+* ⇌ CO*；H2(g)+2* ⇌ 2H* | CO 吸附 1.24（台阶，RPBE）；H 约 1.0 |
| CO 直接解离 | 平台 2.3–2.8；台阶 0.9–1.4 | CO*+* ⇌ C*+O* | 1.00（台阶） |
| CO 氢助活化 | CO+H→HCO 1.51；HCO→CH+O 0.73–0.93；HCOH 路径 | CO*+H* ⇌ HCO*；HCO* ⇌ CH*+O* | 1.50 / 0.90 |
| CHx 加氢 | C+H 0.41–0.85；CH2+H 0.41–0.63；CH3+H 0.88–1.09 | C→CH→CH2→CH3→CH4 | 0.75 / 0.75 / 0.42 / 0.92 |
| 除氧 | O+H 0.73（台阶）–1.72（平台）；OH+H 1.42–1.61；2OH 0.72 | O+H、OH+H、2OH | 0.73 / 1.00 / 0.72 |
| 生成 CO2 | 未找到钴的数值 | CO*+O* → CO2 | 1.30（假设） |
| 链增长 | CHx+CHy 0.05–1.84（CH+CH2 0.74）；CO 插入 0.83 | Rn*+CH2* → R(n+1)* | 0.70 |
| 链终止 | 未找到钴的数值 | Rn*+H* → 烷烃；Rn* ⇌ En*+H*；En* → 烯烃 | 1.00 / 0.80 / 0.55（假设） |
| 烯烃再吸附 | 乙烯吸附强约 0.2 | 脱附能随链长增加；乙烯额外 +0.2 | — |

链长计算到 C80（α = 0.9 时 C80 以上的碳不到 0.5 %）。

## 2. 结果

| 指标 | 实验 | 纯 DFT 参数 | 拟合 A | 拟合 B | 拟合 C | 拟合 D |
|---|---|---|---|---|---|---|
| TOF（s⁻¹） | 约 0.02 | 17 | 0.064 | 0.070 | 0.072 | 0.105 |
| CH4 选择性 | 5–10 % | 91 % | 6.7 % | 7.2 % | 7.9 % | 6.8 % |
| α（C10–C20） | 0.88–0.92 | 0.25 | 0.90 | 0.91 | 0.90 | 0.89 |
| C5+ 选择性 | 80–91 % | 0 % | 82 % | 81 % | 82 % | 81 % |
| C3 烯/烷 | 约 3（宽容差） | 38 | 1.5 | 1.5 | 1.2 | 1.3 |
| 表观活化能（kJ/mol） | 95–105 | 105 | 119 | 128 | 135 | 125 |
| H2 级数 | 0.5–0.8 | −0.14 | −0.08 | −0.07 | −0.14 | 0.05 |
| CO 级数 | −0.2 ~ −0.6 | 0.05 | 0.11 | 0.02 | −0.02 | −0.06 |

模型变体：A 单位点；B 加上“CO 覆盖度约 0.45 ML”的软约束；C 再让 CO 解离需要两个相邻空位；D 再让 H 吸附在独立的一组位点上。拟合时每个参数以 DFT 值为先验，偏离按先验不确定度 σ 计入代价。

## 3. 结论

1. **纯 DFT 参数不行**：TOF 高约 800 倍，CH4 约 90 %，α 只有 0.25。这与文献一致：低覆盖度 DFT 参数的 MKM 普遍给出过多甲烷（Rommens 2024 用低覆盖度能垒得到 43 % CH4；Zijlstra 2020 的 α 只有 0.4–0.5）。
2. **产物分布能拟合**：四个变体都能同时对上 CH4、α、C5+；所需的参数调整大多在 1σ（约 0.2 eV）以内，最大是 CO 解离 +0.25 eV（1.2σ）。拟合后还自然出现了实验中偏离 ASF 的特征（这些都不是拟合目标）：
   - C1 这一步的增长概率约 0.55–0.59，与实验的 0.52–0.57 一致，即 CH4 高于 ASF 直线；
   - 约 C10 以后 α 从 0.84 升到 0.93（双 α），烯烷比随链长下降，来自长链烯烃的再吸附；
   - C2 的烯烷比低于 C3，来自乙烯更强的吸附。
3. **动力学拟合不出来**：四个变体的 H2、CO 反应级数都接近 0（实验分别为正和负），表观活化能偏高 20–35 kJ/mol，TOF 偏高 3–5 倍。扫描 CO 吸附强度发现，让表面被 CO 占满时 CO 级数确实变负，但 CH4 选择性随之大增、H2 级数也变负。也就是说，这类平均场集总模型在只改能垒的情况下，无法同时给出正确的产物分布和正确的压力依赖。文献中能较好复现实验的模型（Rommens 2024）用的是在 CO 饱和表面上计算的、随覆盖度变化的能垒，这正是本模型缺少的。
4. **哪些步骤控制结果**（拟合 D 的速率控制度）：TOF 主要由 CO 直接解离控制（+0.82），除氧贡献很小；CH4 选择性由 CH3+H 加氢（+0.98）、链增长（−0.65）和 CO 解离（−0.53）共同决定。这与 Zijlstra 2020 的结论（CO 解离和除氧控制速率）基本一致。

## 4. 局限

- 21 个可调参数对 8 个实验指标，拟合不唯一，只能作为一致性检验，不能说明参数“被确定”了。
- 链终止、β-H 消除、烯烃脱附、CO2 生成在文献中没有找到钴的数值，先验是假设值。
- 只有一类台阶位（D 加了 H 位），没有平台位、没有覆盖度相关的能垒、没有扩散限制。
- 实验基准来自不同催化剂和条件，本身有 2–3 倍的分散。
