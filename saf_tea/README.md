# CO₂ 制 SAF 技术经济模型：复现、加入中国地区、新增 EtJ-2 路线

依据：Sendlhofer 等，*Fuel* 421 (2026) 139021 正文 + 补充材料（SI）。
所有金额为 2025 年美元；SAF 产量 13.7 t/h × 7884 h = 10.8 万 t/a（SI 物流表与运营成本表反推得到；论文正文的"12 万吨"是名义产能）。

## 文件

| 文件 | 作用 |
|---|---|
| `parse_si.py` | 把 SI 的设备报价表（表 27–30）和可变运营成本表（表 35–46）转成 CSV |
| `model.py` | NPC 模型：论文式 (12)–(16) + SI 表 31–34 的附加系数 |
| `extensions.py` | 中国地区参数（`CN_ASSUMPTIONS`）和 EtJ-2 路线（`ETJ2_ASSUMPTIONS`），所有新假设集中在这里，可直接修改 |
| `run_all.py` | 一键运行，输出 `results/` 下的 CSV、PNG 和 `SAF_TEA_results.xlsx` |
| `data/fig8_digitized.csv` | 论文图 8 的像素读数，作为复现目标 |

运行：`python3 parse_si.py && python3 run_all.py`（依赖 openpyxl、matplotlib）

## 1. 复现结果

12 个场景的 NPC 与论文图 8 的偏差都在 ±1.0% 以内（见 `results/replication_parity.png`）。

复现中确认或推断出的几个隐含设定：

- **运行小时 7884 h/a**：SI 里 CO₂ 费用 ÷ CO₂ 进料量得到。
- **工艺段 FCI = 4.93 × 设备费**：(1 + 直接 2.51 + 间接 0.78) × 1.15；EtJ 再乘 1.2。三个地区都和图 7 吻合。
- **电解 FCI ≈ 1.70 × (800 欧元/kW × 功率)**：功率 = H₂ × 55 kWh/kg。
- **流动资金 WC = TCI 的 10%**；电堆更换 SR = 1 次，ARC = 0.77 × FCI_电解 / 20。
- **固定运营成本只按工艺段 FCI 计算**，不含电解槽。
- **化验费**：SI 表 33 写的是"0.2 × 设备费 EC"，但按 0.2 × 操作人工 OLC 计算才能和图 8 吻合（按 EC 算，EtJ 会偏高约 0.25 美元/kg）。模型默认采用 OLC，可通过 `fixopex_lab_basis="EC"` 切换。
- **EtJ 加氢补充氢**：SI 没给净值，按图 7a 电解槽投资（≈880 MUSD）反推为 267 kg/h。
- **SI 里的笔误**：中东的 MtJ-2 表标成"€"，实际是美元；美国 MtJ-2 的冷却水数值照抄了欧洲。这两处不影响复现结果。

## 3. EtJ-2：CO₂ 一步热催化加氢制乙醇

设定：2CO₂ + 6H₂ → C₂H₅OH + 3H₂O，50 bar，带循环回路。下游的脱水、齐聚、加氢、蒸馏与 EtJ 完全相同，乙醇量相同（34.9 t/h）。

**没有 Aspen 模拟**，所以是简化的物料能量衡算加投资放缩：

- **碳选择性与 MtJ-2 对齐**：按 SI 表 9，MtJ-2 的甲醇碳 / 新鲜 CO₂ 碳 = 99.33%，进合成的 H₂ 比化学计量多 0.78%。EtJ-2 取相同的吹扫损失，不生成 CH₄（`carbon_yield = 1.0`）。敏感性分析中，碳选择性在 0.80–1.00 之间变动（0.80 表示 20% 的碳变成 CH₄ 后吹扫掉）。
- **单程转化率 0.20**：用于计算循环量和压缩功。
- **合成段投资**：以 MtJ-2 甲醇合成段为参照放缩（回路设备取 0.6 次方，进料压缩机取 0.8 次方），去掉甲醇精馏（粗乙醇水溶液直接去脱水）。与 MtJ-2 一致，不加额外投资裕量（`capex_safety = 1.0`；论文对发酵法 EtJ 加了 1.2）。
- **用水抵扣**：反应生成的水（41.0 t/h）直接抵扣脱水单元的配水，因此外购水更少。
- **反应热**（36.6 MW）全部回收为中压蒸汽，计为收入（`steam_recovery = 1.0`）。这样做是为了和 MtJ-2 对齐：论文中 MtJ-2 外输蒸汽约 74 MW（中压 51.5 MW + 低压 22.8 MW），超过了它全流程约 48 MW 的反应热，说明 MtJ-2 的反应热实际上是全部回收的。

物料衡算结果：H₂ 9,515 kg/h（MtJ-2 是 9,449，EtJ 是 9,958），CO₂ 67.2 t/h，工艺段 FCI 约 168 MUSD（欧洲；EtJ 是 701，MtJ-2 是 175）。

## 4. 结果（USD/kg SAF）

| 地区 | FTS | MtJ-1 | MtJ-2 | EtJ | EtJ-2 |
|---|---|---|---|---|---|
| 欧洲 | 6.44 | 5.80 | **4.52** | 5.82 | 4.72 |
| 美国 | 3.49 | 3.45 | **2.68** | 3.95 | 2.89 |
| 中东 | 8.26 | 6.98 | **5.36** | 6.74 | 5.65 |
| 中国 | 2.51 | 2.45 | **1.84** | 2.60 | 1.96 |

化石 Jet A-1 约 1.04 USD/kg。

### 主要结论

1. **中国在 4 个地区里最便宜**：MtJ-2 为 1.84，约为化石航煤的 1.8 倍，而其他地区是 2.6–5 倍。但中国的电价其实比美国贵。从美国 MtJ-2（2.69）逐项换成中国参数，各项影响如下（`results/decomposition_us_to_cn_mtj2.csv`）：

   | 换成中国参数的项目 | 对 NPC 的影响（USD/kg） |
   |---|---|
   | 电价 | **+0.28** |
   | 电解槽单价 | **−0.48** |
   | 设备地区系数 | −0.09 |
   | CO₂ 原料价 | **−0.49** |
   | 利率 | −0.03 |
   | 其他 | −0.05 |

   中国的优势一半来自便宜的电解槽，另一半来自 CO₂ 价格假设。如果 CO₂ 仍按论文的 127 USD/t 计算，中国 MtJ-2 是 2.33，仍然最低。

2. **路线排名在中国不变**：MtJ-2 最优，FTS 和 MtJ-1 接近。EtJ 的发酵罐投资折算到中国后降低了，但仍然偏高。

3. **EtJ-2（碳损失、投资裕量、蒸汽回收都与 MtJ-2 对齐后）**：四个地区都是第二便宜的电制路线，只比 MtJ-2 贵 0.12–0.29 USD/kg，比发酵法 EtJ 便宜 0.64–1.10。用氢量（9,515 kg/h）、电解投资、资本回收都和 MtJ-2 几乎相同，工艺段 FCI 甚至略低（中国 90 对 94 MUSD）。剩下的差距（中国 0.12）几乎全部是蒸汽和液化气副产收入：MtJ-2 外输约 74 MW 蒸汽，EtJ-2 只有合成段的 36.6 MW。这是因为论文的 EtJ 下游（乙醇脱水为吸热反应）本身不外输蒸汽，而 MtJ-2 的甲醇制丙烯高温段可以产生额外蒸汽。如果碳选择性降到 0.80，中国 EtJ-2 升到 2.59。要追平 EtJ，碳选择性需要达到：中国 0.80、美国 0.76、欧洲 0.84、中东 0.86。

4. **中国 MtJ-2 的敏感性**（`results/tornado_china_mtj2.png`）：
   - 绿电价格 0.15–0.40 元/kWh → NPC 1.28–2.68，影响远大于其他参数；
   - 电解槽价格 250–947 USD/kW → 1.66–2.30；
   - CO₂ 原料价 → 1.77–2.33；
   - 碳价从 62 元涨到 200 元/t → 2.25。

## 5. 局限

- 中国和 EtJ-2 的结果都是在论文模型框架内用参数替换和放缩得到的，**没有重新做 Aspen 流程模拟**。
- EtJ-2 的催化剂性能用的是文献中较好水平的假设，目前 TRL 约 3–4。
- 中国工厂沿用了论文"全年连续运行 7884 h、用电网绿电"的假设。如果改成离网风光电，电解槽开工率会大幅下降，需要另建储氢或储电模型。
- 论文本身未计氧气副产收入，也不考虑货币时间价值，本模型保持一致。

## 6. 中国新增路线：HEFA 和干重整（DRM-FT）

只对中国计算，运行 `python3 cn_routes.py`（需要先跑过 `run_all.py`）。所有假设集中在 `cn_routes.py` 的 `HEFA_ASSUMPTIONS`、`DRM_ASSUMPTIONS` 里，可以直接修改。

### HEFA（地沟油加氢，最大航煤模式）

| 假设 | 取值 | 说明 |
|---|---|---|
| 每吨原料产出 | SAF 0.50 t、可再生柴油 0.17 t、石脑油 0.07 t、LPG 0.06 t | 文献常见区间，**估计值** |
| 耗氢 | 0.040 t / t 原料 | 由现场碱性电解槽供应 |
| 工艺耗电 | 60 kWh / t 原料 | **估计** |
| 工艺供热 | 天然气 1.2 GJ / t 原料 | **估计** |
| 地沟油价格 | 7,500 元/t（≈1,050 USD/t） | 2024 年出口离岸价 910–970 美元，再计入出口退税取消（**估计**） |
| 投资 FCI | 600 USD 每吨年产液体产品 | 50 万 t/a 约 21 亿元，**估计** |

### DRM-FT（甲烷干重整 + 费托合成）

- **工艺**：用电加热的干重整炉（CH₄ + CO₂ → 2CO + 2H₂）替代论文 FTS 路线中的 rWGS；费托合成、加氢裂化、精馏都不变，碳效率也按论文 FTS 路线取。
- **进料**：CH₄:CO₂ = 1:1（摩尔比），CO₂ 42.2 t/h，CH₄ 2.15 万 Nm³/h。
- **电解氢**：只需 4,318 kg/h 来补足 H₂/CO 比，约为纯 CO₂ 路线的 36%。
- **额外加热**：重整反应吸热比 rWGS 多 44 MW，全部按用电计。
- **投资**：在 FTS 设备清单基础上加 15 MUSD 重整炉，再乘 1.2 的裕量（积碳风险、技术成熟度 TRL 5–6）。
- **甲烷价格**：3.0 元/Nm³（工业管道气与生物天然气的价格相近）。
- **注意**：用化石天然气时，一半的碳来自化石，产品不算低碳 SAF。要计入减排，必须使用生物甲烷或沼气。

### 敏感性分析

单因素分析，其余参数取基准值。结果见 `cn_tornado_grid.png`、`cn_sweep_*.png`，以及 Excel 的"中国敏感性"和"中国交叉点"两个工作表。

- **电制路线（FTS、MtJ、EtJ、EtJ-2、DRM-FT）**：绿电价格是第一敏感因素。电价从 0.15 变到 0.40 元/kWh 时：
  - MtJ-2：1.28 → 2.68
  - FTS：1.53 → 4.00
  - DRM-FT：1.15 → 2.65
- **第二敏感因素**：
  - MtJ 和 EtJ：电解槽价格
  - FTS 和 DRM-FT：碳价（因为工艺用电量大，碳价通过电价补偿传导）
  - EtJ-2：乙醇碳选择性
- **HEFA 基本不受电价影响**：主要看地沟油价格。地沟油从 5,500 到 9,500 元/t，HEFA 成本从 1.54 到 2.66；航煤收率的影响次之。
- **交叉点**：
  - 绿电低于 **0.30 元/kWh** 时，MtJ-2 比 HEFA 便宜；
  - 地沟油低于 **6,580 元/t** 时，HEFA 比 MtJ-2 便宜；
  - 天然气（或生物甲烷）低于 **3.41 元/Nm³** 时，DRM-FT 比 MtJ-2 便宜；低于 **4.65 元/Nm³** 时，比 HEFA 便宜。
- **年运行小时**：从 8,500 h 降到 5,000 h，电制路线成本上升 0.1–0.3 USD/kg。如果是离网风光电，运行小时可能只有 3,000–4,500 h，需要储能或储氢，本模型没有包含这部分成本。
