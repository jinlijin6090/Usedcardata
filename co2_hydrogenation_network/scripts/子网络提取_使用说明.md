# 子网络提取：指定反应物、产物和步数范围，把中间的反应网络单独拿出来

脚本是 `subnet_extract.py`。它在物种级数据库上工作（一个物种一个节点、不含离子、不含伪物种）：
- 全量版：`data/net_C16_species/`；
- 推荐版：`data/net_C16_shape_species/`。

## 用法

```bash
cd co2_hydrogenation_network/scripts
python subnet_extract.py ../data/net_C16_species --from CO2 --to 对二甲苯 --extra 1 --max-c 8 --out 对二甲苯_k1
```

| 参数 | 含义 |
|---|---|
| `--from` | 起始反应物，可以写多个，例如 `--from CO2 甲醇` |
| `--to` | 目标产物，可以写多个；多个目标时取各自子网络的并集 |
| `--extra k` | 允许比最少步数多几步。默认 0，只要最短路线 |
| `--pool` | 始终可用的小分子，默认 `H H2 H2O`；`--pool none` 表示一个都不给 |
| `--max-c N` | 只使用碳数不超过 N 的物种（强烈建议，原因见下） |
| `--exclude 族…` | 不使用某些反应族，例如 `--exclude R:abs R:beta` 去掉气相自由基反应。一个方程的所有族都被排除才会去掉 |
| `--out` | 输出文件夹 |

物种的写法：
- SMILES，任意写法都可以，共振式也能识别；
- 数据库里的 label；
- 常用名：CO2、CO、H2、甲醇、甲烷、乙烯、丙烯、苯、甲苯、对二甲苯、间二甲苯、邻二甲苯、乙苯、萘、正十六烷、正十二烷、正辛烷、异辛烷、环己烷等。

第一次读全量数据库要 2–3 分钟，之后会在数据库目录里留一个 `_cache.pkl`，再运行只需几秒。

## 输出（都在 `--out` 文件夹里）

| 文件 | 内容 |
|---|---|
| `网页.html` | 双击打开。每一列是"最早第几步能生成"。可以按"额外步数"筛选（0 = 最短路线），单击物种看结构式和它在子网络里的所有反应，支持搜索 |
| `物种.csv` | node_id、SMILES、名称、类别、分子式、最早第几步生成 f、最晚第几步需要 L、角色（起始 / 目标 / 中间体 / 小分子池） |
| `反应.csv` | 方程（按实际使用的方向）、反应族、最早第几步、额外步数、时间余量、对应的原始基元反应数、输入和输出的 node_id |
| `subnet.json` | 同样的内容，JSON 格式 |
| `subnet.graphml` | 物种和反应两类节点组成的二部图，可以用 Cytoscape、Gephi、networkx 打开 |
| `说明.txt` | 这次的查询条件、各目标的最少步数、k = 0…设定值时各自的反应步数 |

CSV 用带 BOM 的 UTF-8，Excel 直接打开不会乱码。

## 判据（"步"是怎么算的）

- **最少步数（f）**：从起始反应物（加上小分子池）逐层推。一个反应步的所有反应物都已经到手，它就能在下一步发生。这和网页里路径搜索的定义一致。目标的最少步数记为 D。
- **最晚时间（L）**：从目标往回推，每个物种最晚必须在第几步之前拿到，才能让目标在 D + k 步内生成。往回推时会经过每一步的全部反应物，所以给甲基化提供 CH₃ 这类共反应物的支路也会被算进去。
- **收录条件**：一个反应步最早能发生的步数 ≤ 它最晚必须发生的步数，就收进子网络。
- **额外步数**：这个反应步在 k 至少为几时才会被收进来。0 表示它在某条最短路线上。
- 以目标为反应物的反应步不收，例如对二甲苯 → 间二甲苯 → 对二甲苯这种绕圈。

## 为什么建议加 `--max-c`

步数是按"层"算的，而分子筛里的齐聚一步就能让碳数翻倍。所以只要多给一步，"先长到 C10–C16，再裂解、异构回来"这一整类路线就都能按时到达目标，子网络会一下子变得很大。以推荐版、CO₂ → 对二甲苯为例：

| 条件 | k = 0 | k = 1 | k = 2 |
|---|---|---|---|
| 不限碳数 | 167 个反应步 | 262 038 | 401 415 |
| `--max-c 9` | 167 | 14 489 | 17 585 |
| `--max-c 8` | 167 | 5 581 | 6 419 |

这个膨胀不是程序出错，而是网络本身高度连通的结果。如果关心的是"直接路线"，就把碳数上限设成目标的碳数，或者稍大一点。

子网络超过 20 万个反应步时（可用 `--max-reactions` 调整），只导出表格，不生成网页，因为浏览器画不动。
