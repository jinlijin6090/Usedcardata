# CO₂ 加氢 C1–C16 物种级数据库：一个物种一个节点，不含离子

来源：全量 C16 网络 `net_C16_full`（5 283 977 个物种、16 977 234 条反应，含全部 C1–C16 骨架，无择形限制），由 `scripts/species_merge.py` 生成。

## 合并规则

| 原来的写法 | 合并成 |
|---|---|
| 分子筛酸位碳正离子 R⁺（即表面烷氧基 R–O–Z 或 R⁺···Z⁻ 离子对）、金属位吸附烷基 R*、气相自由基 R• | 同一个"R 基团"节点：同一骨架、同一位点少一个 H。用中性的开壳层 SMILES 表示，例如 `C[CH]C` |
| 烯丙基、戊二烯基等共振结构的不同写法 | 一个节点。SMILES 取全部共振式中字典序最小的那个；其他写法记在 `aliases` 表里 |
| H⁺（酸位 H–Z）、H*（金属位）、H• | H 原子 `[H]` |
| CO₂^δ−*（活化吸附） | CO₂ |
| H₂CO* | 甲醛 |
| SMS（表面甲氧基 CH₃–O–Z） | 甲基 `[CH3]` |
| 其他 C1 表面物种（HCOO*、H₂COO*、CH₃O*、HCO*、HCOH*、CH₂*、CH*/C*、CO*） | 对应的中性分子或碎片 |

每个节点的 `states` 列记下它在原网络里以哪些形式出现，例如"酸位 R⁺；金属位 R*；气相自由基 R•"。所以机理信息没有丢。

## 生成器简写的修正与伪物种的去除

修正后，数据库里没有伪物种，每条反应都元素守恒（C、H、O 全部配平）。

| 原写法 | 改为 |
|---|---|
| M:CO：R* + CO* → 醛（少一个 H） | R + CO ⇌ 酰基 RC(=O)，再接 RC(=O) + H ⇌ 醛（新族 M:acylH）；为此新增 80 919 个酰基节点 |
| H₂COO* + H* → H₂CO* + H₂O（少一个 H） | 经过 H₂COOH 分两步 |
| H₂ → H* | H₂ ⇌ H + H |
| Z:HT 氢转移：A + [H]（氢转移受体，伪物种） → B | A ⇌ B + n H₂（n = 1 或 2，例如四氢萘 ⇌ 萘 + 2 H₂）。这里的 H₂ 表示转移出去的氢，实际是交给了另一个烯烃 |
| 烃池 HCP（集总伪物种）：CH₃ → HCP、HCP → 乙烯 / 丙烯 + H、多甲基苯 → HCP | 删除这些集总步骤，改用显式反应表示烃池化学：芳环甲基化（A:meth）、脱烷基（A:FC 逆反应）、β-H 消除，加上新增的侧链甲基化 A:scm（苄位 C–H + CH₃ ⇌ 侧链多一个碳的芳烃 + H，所有苄位都算） |

## 反应合并

- 重新映射到节点后，相同的方程（正反方向视为同一条）只保留一行。`families` 列出所有给出这个方程的机理族，`n_original` 是它对应的原始基元反应数。
- 合并后，一边只比另一边多出物种、其余完全相同的空反应去掉，例如 CO₂ + H → CO₂（活化吸附那一步）。

## 文件

| 文件 | 列 |
|---|---|
| `nodes.tsv.gz` | node_id、smiles、label（常用名）、kind（类别）、formula、C、H、O、states（原网络中的存在形式）、n_forms（合并的共振写法数）、skeleton（碳骨架） |
| `reactions.part*.tsv.gz` | id、reactants、products（node_id，逗号分隔）、families（分号分隔）、n_original、equation（SMILES 方程） |
| `aliases.tsv.gz` | old_id、old_class、old_key（原数据库的 id、类别和键）、node_id、form_smiles（这个写法的中性形式）。原数据库的每个物种都能查到它被合并到了哪个节点；两个伪物种的 node_id 为空，表示已去除 |
| `stats.json` | 按类别 × 碳数的节点数、按反应族的反应数等 |

## 查询

用 `co2_hydrogenation_network/scripts/species_query.py`，需要 DuckDB 和 RDKit，就是 `environment.yml` 里的环境：

```bash
python species_query.py <本目录> --node "CC=C[CH]CC"          # 一个物种：节点、状态、合并进来的写法
python species_query.py <本目录> --reactions-of "CC(C)=C"     # 一个物种参与的全部反应
python species_query.py <本目录> --old "C[CH+]C"              # 原数据库里的离子 / R* / R• 键对应哪个节点
python species_query.py <本目录> "SELECT kind, count(*) FROM nodes GROUP BY 1 ORDER BY 2 DESC"
python species_query.py <本目录> --export c8.parquet "SELECT * FROM nodes WHERE C = 8"
```

SMILES 怎么写都可以，查询前会先用 RDKit 规范化。共振式的任意一种写法都能查到同一个节点。
