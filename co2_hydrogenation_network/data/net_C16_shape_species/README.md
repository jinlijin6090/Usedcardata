# CO₂ 加氢物种级数据库（推荐版：C1–C12 全部 + C13–C16 择形）

由 `scripts/species_merge.py ../data/net_C16_shape` 生成：一个物种一个节点，不含离子，不含伪物种，所有反应元素守恒。

| 输入 | 输出 |
|---|---|
| 128 390 个物种 | 114 187 个节点（含新增的 2 553 个酰基和 H₂COOH） |
| 367 369 条反应 | 359 149 条节点级反应（含新增的 463 条侧链甲基化） |

从 CO₂ + H₂ 出发（H、H₂O 视为可用）可以到达 114 106 个节点。不可达的 81 个是择形规则排除了前体的 C13+ 取代茚满 / 四氢萘，以及 2 个四甲基环己烷。

合并规则、文件格式和查询方法与全量版相同，见 `../net_C16_species/README.md`；查询脚本是 `scripts/species_query.py`。
