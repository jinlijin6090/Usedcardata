# CO₂ 加氢物种级数据库（推荐版：C1–C12 全部 + C13–C16 择形）

由 `scripts/species_merge.py ../data/net_C16_shape` 生成：一个物种一个节点，不含离子。
- R⁺（酸位烷氧基 / 离子对）、R*、R• 合并成同一个 R 基团节点；
- 共振式合并成一个节点；
- H⁺、H*、H• 合并成 H 原子。

| 输入 | 输出 |
|---|---|
| 128 390 个物种 | 114 189 个节点（含 2 553 个新增的酰基，以及 H₂COOH） |
| 367 369 条反应 | 358 700 条节点级反应 |

不含伪物种的反应全部元素守恒。

合并规则、文件格式和查询方法与全量版相同，见 `../net_C16_species/README.md`；查询脚本是 `scripts/species_query.py`。
