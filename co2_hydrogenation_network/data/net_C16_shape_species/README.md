# CO₂ 加氢物种级数据库（推荐版：C1–C12 全部 + C13–C16 择形）

由 `scripts/species_merge.py ../data/net_C16_shape` 生成：一个物种一个节点，不含离子，不含伪物种，所有反应元素守恒。

| 输入 | 输出 |
|---|---|
| 147 067 个物种 | 132 864 个节点 |
| 418 711 条反应 | 407 504 条节点级反应 |

**2026-11-05 版的改动**：
- 修复了自由基 β-断裂过滤条件的 bug。离去碎片是伯碳自由基或甲基的反应、以及它们的逆反应（例如乙基 + 乙烯 → 丁基）原来被误删，现在补回来了。
- 新增缩合 / 偶联反应：

  | 反应族 | 反应 |
  |---|---|
  | K:aldol | 羟醛加成 |
  | K:crot | 脱水成烯醛 / 烯酮 |
  | K:enH | 烯醛 / 烯酮的 C=C 加氢（与上面两族串起来就是 Guerbet 偶联） |
  | K:keto | 羧酸酮化 |
  | K:DA | Diels–Alder |
  | R:comb | 任意两个烷基自由基的复合 |

- 新增两类物种：β-羟基醛 / 酮，烯醛 / 烯酮。

从 CO₂ + H₂ 出发（H、H₂O 视为可用）可以到达 132 783 个节点。不可达的 81 个是择形规则排除了前体的 C13+ 取代茚满 / 四氢萘，以及 2 个四甲基环己烷。

合并规则、文件格式和查询方法与全量版相同，见 `../net_C16_species/README.md`；查询脚本是 `scripts/species_query.py`。
