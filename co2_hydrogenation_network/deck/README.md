# 反应网络 PPT

`CO2加氢制航煤_反应网络.pptx`：把当前 OX-ZEO 集总反应网络画成网络图，共 8 页。网络图都用原生 PowerPoint 形状绘制，可以直接编辑；第 5 页裂解/齐聚弧线图是图片。通量来自 `../tandem_kinetics/calibration.json` 中的 G1 校准参数。

重新生成（需要 node 和 pptxgenjs，以及 pptx skill 的 apply_theme.js）：

```bash
python fluxes.py && python prep.py && python arcs.py
NODE_PATH=<node_modules> node build.js deck.pptx
```

## 完整反应网络（含自由基）

`CO2加氢C1催化完整反应网络_含自由基.pptx`：参考"零碳 / 低碳催化反应网络"总图的画法，去掉了氨 / 尿素（C–N 偶联）部分，共 3 页，幻灯片尺寸 20 × 12.5 英寸。

1. 总图，65 个节点、75 条反应边，分为以下几个区：
   * 电化学还原；
   * C₁ 表面中间体核心：甲酸盐路线、羧基 / RWGS、CO 加氢与解离、CHₓ 链；
   * 与表面物种一一对应的气相自由基区：HOCO•、HCOO•、HCO•、CH₃O•、•CH₂OH，以及 POM / OCM 中的 •CH₃、CH₃OO•、H•、HO₂•、OH•；
   * 亚硝酸甲酯羰基化制乙二醇；
   * 分子筛（OX-ZEO）：表面甲氧基、乙烯酮、烃池、烯烃循环；
   * 金属位链增长（费托 / FTO、CO 插入制醇）与酸位升级到航煤 / 柴油。

   节点形状表示物种类型，连线颜色表示反应类别，节点右下的圆点表示经过该中间体的反应类别。
2. 全部自由基清单：每个自由基的生成反应、消耗反应和对应的表面物种。
3. 共享中间体表，以及节点和反应边的统计。

```bash
NODE_PATH=<node_modules> node full_network.js out.pptx
```

## 细致反应网络（含自由基，展开版）

`CO2加氢C1催化细致反应网络_含自由基.pptx`：在完整网络的基础上去掉了羰基化（亚硝酸甲酯 → 乙二醇）部分，并把总图里简化的部分逐一展开。

所有网络图的背景色块表示该段反应路径所需的催化剂形式，共 11 类：
* 还原性氧化物 · 氧空位；
* Cu 基 / Cu–氧化物界面；
* 过渡金属；
* 金属碳化物；
* CO 插入双位；
* 载体 / 界面；
* Brønsted 酸分子筛；
* Lewis 酸改性分子筛；
* 双功能金属–酸；
* 电催化阴极；
* 无需催化剂（气相）。

每个色块上的标签写明代表材料，每页底部有色块图例。共 11 页，幻灯片尺寸 24 × 13.5 英寸：

1. 总览：各区标注对应的模块 A–F，并按催化剂形式加了色块。
2. 催化剂形式分类表：每类的代表材料、活性位 / 作用，以及对应的反应路径。
3. 细致总图：六个模块放在同一页，字号较小，适合放大或打印查看。
4. A：氧化物上 CO₂ 活化与甲醇合成，包括：
   * 氧空位循环、H₂ 异裂、甲酸盐路线；
   * RWGS 的缔合与氧化还原两条路；
   * 电化学 CO₂•⁻。
5. B：金属位 C₁ 核心，包括：
   * CO 直接解离 / H 助解离 / 加氢；
   * CHₓ 加氢–脱氢链；
   * SMR / DRM / POM 表面步骤、WGS、积碳 / χ-Fe₅C₂。
6. C：自由基网络，包括：
   * CO₂ → CH₃OH 自由基链；
   * CH₄ 活化 / OCM / POM / C₂；
   * H/O 自由基池的引发、支化与终止。
7. D：费托链增长，C₁ → C₄ 显式写出，Cₙ 用通式，包括：
   * CHₓ 插入、CO 插入制醇；
   * 乙烯基 / 烯丙基机理；
   * 甲基支化、α-烯烃再吸附与双键异构、ASF 分布。
8. E：分子筛，包括：
   * 甲醇质子化 → 表面甲氧基 SMS → DME；
   * 第一个 C–C 键：甲氧甲基阳离子、Koch 羰基化、乙烯酮；
   * 烯烃循环 C₂–C₇：甲基化 / 去质子 / 加氢 / 齐聚 / β-断裂；
   * 芳烃循环：苯 → 七甲基苯鎓⁺，缩环（paring）与侧链机理；
   * 氢转移、积碳。
9. F：双功能加氢异构 / 裂化，包括：
   * PCP 逐级支化；
   * β-断裂 A / B / C 型；
   * 烯烃齐聚制航煤（SPK）。
10. 全部自由基清单。
11. 各模块的物种与反应边统计：80 个分子、53 个表面物种、15 个自由基、17 个离子，共 183 条反应边。

NODE_PATH=<node_modules> node detailed_network.js out.pptx
